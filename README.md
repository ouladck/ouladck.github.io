# Karim Oulad Chalha - Personal Portfolio

This repository hosts the personal portfolio website for Karim Oulad Chalha, a Full Stack Developer with over 10 years of experience. The site showcases his professional journey, skills, education, and awards.

## Technologies Used

*   **HTML5**: For structuring the content.
*   **CSS3**: For styling and responsive design.
*   **JavaScript (ES6+)**: For interactive elements and animations.

## Features

*   **Responsive Design**: Optimized for various screen sizes (desktop, tablet, and mobile).
*   **Clean and Modern UI**: A professional and easy-to-navigate user interface.
*   **Dynamic Content**: Subtle animations for an enhanced user experience.
*   **Profile Section**: Introduction with profile picture and social links.
*   **About Me Section**: Detailed biography.
*   **Experience Timeline**: Chronological display of professional experience.
*   **Education Timeline**: Overview of academic achievements.
*   **Awards Section**: Recognition of notable achievements.

## Setup and Installation

To get a local copy up and running, follow these simple steps.

### Prerequisites

You need to have Git installed on your system.

*   [Git](https://git-scm.com/downloads)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/ouladck/ouladck.github.io.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd ouladck.github.io
    ```
3.  **Open `index.html` in your browser:**
    Simply open the `index.html` file located in the root of the project to view the portfolio locally.

## Deployment

This portfolio is designed to be hosted on GitHub Pages.

1.  **Repository Naming**: Ensure your repository is named `YOUR_USERNAME.github.io` (in this case, `ouladck.github.io`).
2.  **Push to `main` branch**: Push your code to the `main` branch of this repository. GitHub Pages will automatically deploy the content of the `main` branch.
